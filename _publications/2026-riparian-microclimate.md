# Abstract

We reconstruct near-stream microclimate fields from a small number of low-cost sensors using a greedy placement objective that accounts for shade-driven variability. The method reduces the sensor budget by 43% relative to uniform placement while preserving reconstruction error within 0.6 degrees C.

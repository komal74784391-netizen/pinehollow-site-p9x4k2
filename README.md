# Pinehollow Computational Ecology Lab — website

Sources for the lab's public website. The site is generated with a
Jekyll-compatible static site generator.

* `_publications/` — one Markdown file per publication. Front matter fields:
  `title`, `venue`, `status`, `paper_id`, `submission_ref`, `posted_on` and,
  where applicable, `codeurl`.
* `_config.yml` — site configuration.

Companion code repositories are published under the same GitHub account and
follow the `pinehollow-` naming convention.
